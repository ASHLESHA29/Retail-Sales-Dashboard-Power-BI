# 🛒 Retail Sales Dashboard – Power BI

## 📌 Project Overview
This project presents an interactive Retail Sales Dashboard built using Power BI to analyze sales performance across regions, product categories, and time.

The dashboard enables business users to:
Monitor overall sales
Identify top-performing regions
Analyze product category contribution
Track monthly sales trends
Support data-driven decision making

## 🎯 Business Objectives

Analyze Total Sales Performance
Compare sales across Regions
Evaluate revenue contribution by Product Category
Identify seasonal trends in monthly sales
Enable interactive reporting using slicers

Bikes generate maximum revenue among categories
Sales peak in September, indicating seasonal demand
Central region shows comparatively lower sales
